# Aviso de atribución

Botica LyP es una aplicación construida sobre el framework abierto Meralda.

- Framework original: Meralda / mwPHPlib
- Autor del framework: Rodrigo Vecco Haddad
- Repositorio del framework: https://github.com/rodrigovecco/meralda
- Licencia del framework: MIT

Las funciones específicas de productos, inventario, pedidos, cobranza y reportes se encuentran en el módulo `pharmacy` de este repositorio.
