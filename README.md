# Botica LyP

Sistema web administrativo para la gestión de una botica, desarrollado en PHP sobre el framework Meralda.

## Funciones principales

- Gestión de productos.
- Control de inventario y stock.
- Registro de pedidos.
- Módulo de cobranza.
- Emisión e impresión de tickets.
- Reportes administrativos.
- Administración de usuarios y permisos.
- Alertas de productos con poco stock o próximos a vencer.
